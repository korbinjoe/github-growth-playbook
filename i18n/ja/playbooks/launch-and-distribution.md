# 個人開発者の公開・拡散ガイド

[English](../../../playbooks/launch-and-distribution.md) | [简体中文](../../zh-CN/playbooks/launch-and-distribution.md) | **日本語** | [Français](../../fr/playbooks/launch-and-distribution.md) | [Deutsch](../../de/playbooks/launch-and-distribution.md)

このガイドは[初回調査](../research/github-personal-developer-growth-2024-2026.md)からの分析です。本リポジトリの管理者が実施・検証した実験集ではありません。

## 1. 価値を確認できる素材を作る

一文の需要説明、実際の入力と出力、比較画像か短い動画、試用入口か短い導入手順、使える例、現在の制限を用意します。

初めて見る人が利点を理解し、初回試用を完了できるか確認します。

## 2. 関連する二つのコミュニティで反応を得る

対象者に合わせて選びます。デモを公開し、質問に答え、実際の用途と繰り返す障害を記録します。

試用成功、自発的な共有、手順紹介、貢献を観測します。Starは利用者数と別に扱います。

## 3. 実利用の後に振り返りを公開する

構成：需要 → 最初の反応 → 判断と失敗 → 結果 → 応用できる学び → 試用入口。

日付、期間、累計か増分、ダウンロードか利用者、自己申告か独立記録を明記します。不明点は残します。

## 4. 他者が紹介できる素材を用意する

| 対象 | 素材 |
| --- | --- |
| 編集者・ニュースレター | 短い説明、比較か動画、試用、対象者、制限、作者の背景 |
| 手順の発信者 | 短い操作、動く例、よくある問題、版の情報 |
| 制作者 | テンプレート、モデルやテーマ、制作手順、完成品の集まり |
| 連携する開発者 | API、互換性、サンプル、拡張文書 |

## 5. 一回の実験を記録する

[実験テンプレート](../templates/growth-experiment.md)を使い、仮説、公開日、入口、結果を残します。訪問、試用成功、継続利用、Starは別に記録します。根拠なしに全成長を一つの告知へ帰属させません。

## 紹介文

> 【対象者】の【具体的問題】を解決するオープンソースの【ツール】を作りました。
>
> 【確認可能な改善】ができます。デモ／比較：【リンク】。
>
> 試用：【リンク】。リポジトリ：【リンク】。
>
> 現在の対応範囲は【範囲】、制限は【制限】です。実利用での反応を歓迎します。

## 振り返りのタイトル例

- 【問題】のために作ったツール：最初の利用者から学んだこと
- 公開から実際の利用まで：【期間】の振り返り
- 【能力】を使える製品にする：需要、判断、失敗

タイトルは証拠に合わせます。事例での急増を実験の保証された結果として扱いません。

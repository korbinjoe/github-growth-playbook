## 継続して記録する

1. 作者の初投稿、振り返り、リリース記録、実際の記事を探す。
2. テンプレートで時系列を作り、主要な事実に出典を付ける。
3. 自己申告と推論を明示し、不明点を残す。
4. 再利用できる行動をガイドにまとめ、実施後に結果を記録する。
5. 過去の整理日を保持し、重要な訂正を記録する。

事例は `cases/`、調査は `research/`、実践は `playbooks/` に置きます。情報提供はIssue、変更はPull Requestで受け付けます。各文書の言語選択から同じ文書の5言語版へ移動できます。

## 証拠の限界

- 中国語READMEだけでは作者の中国本土在住を証明できません。
- 個人で始めても、その後に共同開発や企業支援へ移る場合があります。
- 時系列は因果関係を証明せず、掲載だけで訪問数や転換数は分かりません。
- 公開記録のある成功例に偏るため、生存者バイアスがあります。成長、売上、資金調達は保証されません。
- 自分たちの分析と短い引用を保存し、第三者の記事やメディアにはリンクします。

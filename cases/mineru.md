## Growth interpretation

Inference: downstream products can introduce a tool to users who never discovered its repository directly. Clear formats, interfaces, and compatibility materials make integration easier. A listed integration is a distribution opportunity, but not automatically an independently measured growth cause.

## Reusable actions

- Provide representative input/output files and explain supported formats.
- Publish a minimal integration example and version compatibility notes.
- Track active integrations and successful processing tasks separately from direct repository visits.

## Unresolved questions

- Which integrations led to repeat use, and how many users arrived through them?
- What did the maintainers do before the first major Trending appearances?

These actions are recommendations, not independently measured channel effects. The original 2026-10-10 snapshot is retained; totals do not represent two-year additions or users.

## Growth interpretation

Inference: documentation and working examples can make a demanding task easier to reproduce and teach. Compatibility with models users already want can generate repeated reasons to revisit a tool. Continued attention is documented; the initial breakout and each model release’s acquisition effect are not.

## Reusable actions

- Publish a working example for one identifiable task before presenting broad capability lists.
- Make compatibility, prerequisites, and reproduction steps explicit.
- Treat meaningful support updates as new teaching material and measure successful task completion.

## Unresolved questions

- Which original announcement or tutorial produced the first major growth change?
- Which supported workflows are repeatedly used, rather than only starred?

These actions are recommendations, not independently measured channel effects. The original 2026-10-10 snapshot is retained; totals do not represent two-year additions or users.
